Getting started

Point at a step (or tap it) to see how it's done. Steps 2 to 4 are a one-time thing.

bar 1

Open Teto Relay

Right-click its icon on the taskbar and pin it, so it's always there.

bar 2

Press Check setup

Anything in red needs fixing, and it tells you how.

bar 3

Pick a voice

Choose a voicebank from the list, or drop a .zip onto Add a voicebank.

bar 4

Set your mic and output

Microphone: your real mic. Output: CABLE Input. No save button, it just sticks.

bar 5

Press Start

The very first start takes a minute while it loads. Then hold F8 and talk.

Discord & OBS

Teto Relay plays into VB-Cable, and Discord or OBS pick her up from the other end.

Discord
User Settings → Voice & Video → Input Device: CABLE Output
OBS
Sources + → Audio Input Capture → CABLE Output

Don't set Teto Relay's Microphone to CABLE Output. She'll hear herself and keep singing in a loop. It should always be your real mic.

What the buttons do

These are on the main screen. Everything else is under All settings.

Language

Pick the language you speak. Any voicebank can sing all three.

Singing style

Speech copies your voice exactly. Sung snaps it to a key and adds vibrato.

Double voice

Layers a second voice for a fuller sound, only on lines you sing.

Song lyrics

Singing an actual song? Paste the lyrics in first so every word comes out right.

Transpose & volume

Shift her higher or lower, and set how loud she is.

Push-to-talk key

F8 by default. Change it if another app already uses F8.

If something's wrong

Press Check setup first. It usually knows what's up. If not:

Plain beeps instead of Teto

OpenUtau didn't start. Install the .NET 8 Desktop Runtime, or set All settings → Setup → OpenUtau folder to the folder that has OpenUtau.exe.

She hears herself and loops

Your Microphone is set to CABLE Output. Set it to your real mic.

Nothing happens when I hold F8

Another app is grabbing F8. Pick a different Push-to-talk key.

"No output device matching CABLE Input"

Install VB-Cable and restart Windows, or choose another Output.

"The microphone is not available"

Plug it back in, or close whatever app is using it. Still stuck? Press Stop, then Start.

A word comes out wrong or silent

Turn on All settings → Setup → Keep what I said. Every phrase you say gets saved next to what she sang, so you can send both in.

Where your files are

Uninstalling doesn't delete your settings, voicebanks or downloaded models.

Installed%LOCALAPPDATA%\TetoRelay

Settings, voicebanks and models. Delete this folder too if you want it all gone.

Portable zipdata\

Everything is kept in the data folder next to TetoRelay.exe.
